# Madkhal

Madkhal (مدخل, "intake") is an open source decision support tool, prepared as a student
proposal seed, that turns imperfect satellite algal bloom evidence into an auditable GO,
DERATE or PARK advisory for a hypothetical seawater reverse osmosis intake.

This README is a placeholder during the build. See `STATUS.md` for what works today.

Evidence: real satellite history from the Nadhir hindcast. Plant, drone and consequences:
hypothetical, synthetic parameters. Madkhal is advisory software for planning and learning;
it controls nothing.
